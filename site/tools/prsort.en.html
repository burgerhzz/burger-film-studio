PR Sort

One-click sorting for Premiere project packages

How it used to work

Packaging a project with Premiere's Project Manager dumps every file into one flat folder: footage, music and project files all mixed together. Whoever takes over opens the folder and can't tell where anything is.

What it changes

  • Sorted the way editors expectDrop the folder into the app and it's organised into a structure editors already know, so whoever takes over can find things by folder name:
  • Projects/Project files and Premiere caches
  • Footage/One folder per camera (CAM_A, B, C), with photos and voice-over kept separate
  • Assets/Motion graphics, music and sound effects, with music and SFX split at 90 seconds
  • Exports/Rendered files

Files it isn't sure about get an orange question mark and a drop-down so you can decide.

Core features

  • Moves within the same drive only: no renaming, copying or deleting
  • Every move is logged and can be undone in one click
  • Runs on Intel and Apple silicon Macs

Decisions behind it

Once, a project wouldn't open after sorting. It looked like the tool had broken it, but the package had come out of Premiere already broken. So step one of the instructions became: open the project once before sorting to make sure it works.
