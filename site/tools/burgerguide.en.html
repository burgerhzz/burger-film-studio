burgerGuide

Video safe-zone preview

How it used to work

Text cards, logos and faces in short-form video often end up hidden behind platform buttons and captions, and you only find out after posting. The options used to be a downloaded safe-zone template with a single layout, or dragging guides by hand.

What it changes

  • No template huntingRealistic TikTok, Instagram Reels, Facebook Reels and YouTube Shorts interfaces are built into the panel and drop onto the top track in one click.
  • Switchable layoutsEach platform has its own overlay, plus a conservative frame that's safe on all three and a 16:9 YouTube layout.
  • No more manual guidesRule of thirds, centre cross, action-safe and title-safe areas are a toggle away, and custom grids can be saved as presets.
  • One opacity sliderEverything is merged into a single clip, so one slider controls the opacity.

Core features

  • Realistic UI for four platforms
  • Safe-on-all-three frame
  • 16:9 YouTube layout
  • Rule of thirds, centre cross, action-safe, title-safe
  • Custom grids saved as presets

Decisions behind it

Premiere doesn't let extensions draw guides, so the overlay is a transparent image on its own track. The trade-off: that track has to be switched off before export, or the overlay will be rendered too.
