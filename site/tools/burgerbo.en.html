Premiere Pro extension

burgerbo

YouTube videos straight into Premiere

How it used to work

Edits often need clips from online videos. That used to mean finding a download site, downloading, transcoding when the resolution or codec was wrong, importing and dragging it onto the timeline, for every single clip.

What it changes

  • All in one goPaste a URL in the Premiere panel, choose a resolution, and it downloads, transcodes, imports and places the clip on the timeline.
  • No unnecessary transcodesH.264 sources are imported as-is; it only transcodes when it has to.
  • Batch itPaste a whole list of URLs with ⌘V and they queue up.

Core features

  • Up to 4K
  • ProRes 422 output
  • Batch download queue
  • Choice of timeline placement

Decisions behind it

Batches run one clip at a time, not in parallel. Bandwidth and transcoding are shared, so running three at once just makes all three slower, and the progress bar can't say which one it's talking about.

One failure doesn't stop the batch. When it's done, successful clips leave the queue and failed ones stay, so what's left is exactly the retry list.

Enter used to start the download; it now adds the URL to the list, because building a list shouldn't need the mouse for every clip. Pressing Enter on an empty field still starts the download, so the old habit costs one extra key.
