用 Claude Code 搭的剪輯流程 Claude Code Workflows

  1. 01

    MG 開場動畫

    給一包素材和旁白 mp3，做出 1080p 的紙張拼貼風動態圖像，畫面跟著旁白逐字進場。音效依動畫裡每個元素實際開始動的那一格來混，不是照旁白估時間。

    用在：國際醫學解碼 EP5 開場，82 秒

  2. 02

    圖卡動畫

    一張資訊圖卡加一段旁白，做成 1080p 動畫，旁白講到哪個區塊，那個區塊才進場。

    用在：宋醫師節目的「支撐力」「容積力」「彈力」圖卡

  3. 03

    重點字卡批次上字

    用自己在 Premiere 做的字卡範本，照台詞批次換字、放上時間軸。黃字放數字和結論，白字放鋪陳。

    用在：國際醫學解碼的重點字

  4. 04

    自動組片

    把動畫對齊醫師講話放上序列，剪掉動畫裡的停頓；照字幕台詞挑 b-roll，列清單確認後下載、放上時間軸；配樂交叉淡化。

    用在：國際醫學解碼 EP5

  5. 05

    自動粗剪（團隊版）

    校正逐字稿、依腳本挑重點，產生 Premiere 粗剪序列。三台攝影機用聲音自動對時，誰在講話就切到誰的特寫，同時切換麥克風。

    用在：Cofit 影音組，附團隊安裝教學
