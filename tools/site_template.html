一集節目怎麼做：用 Claude Code 串起來的剪輯流程 Claude Code Workflow

照實際製作順序排列，點卡片看細節。

  1. STEP 01

    字幕依腳本校正

    burgerSub 字幕＋節目腳本 → 校正好的字幕，重錄只留最後一版

    對照節目腳本修正語音辨識的錯字，時間碼一格都不動。同一句念了好幾次的，只留最後一版。

    這一步我確認什麼聽不清楚的句子不猜，列出時間點由我聽原音

    用在：國際醫學解碼 EP5：1,061 句字幕改了 161 句，去掉重錄後剩 819 句

  2. STEP 02

    自動粗剪

    校正好的字幕＋三機素材 → Premiere 粗剪序列

    依腳本挑重點，產生 Premiere 粗剪序列。三台攝影機用聲音自動對時，誰在講話就切到誰的特寫，同時切換麥克風。

    這一步我確認什麼挑哪些重點、剪成多長由我決定

    用在：Cofit 影音組團隊版，附安裝教學（動畫為示意）

  3. STEP 03A

    MG 動畫

    素材包＋參考影片＋旁白 mp3 → 跟著旁白進場的 MG 動畫

    參考影片定風格，素材包排版，畫面跟著旁白逐字進場，開場、段落說明都能用。音效依動畫裡每個元素實際開始動的那一格來混，不是照旁白估時間。

    這一步我確認什麼每一版先出分鏡抽格圖，我看過才輸出

    用在：國際醫學解碼 EP5 開場（82 秒，這裡節錄開頭並加速播放）

  4. STEP 03B

    圖卡動畫

    資訊圖卡＋旁白 mp3 → 跟著旁白進場的圖卡動畫

    旁白講到哪個區塊，那個區塊才進場，皮膚分層依序亮起。

    這一步我確認什麼抽格確認每個元素的進場時間

    用在：宋醫師赫蓮娜：彈力從哪來、PX50 真皮層刺激（兩段合併加速）

  5. STEP 04

    自動組片

    精剪序列＋動畫 → 動畫、b-roll、配樂上時間軸

    把動畫對齊醫師講話放上序列，剪掉動畫裡的停頓；照字幕台詞挑 b-roll，下載後放上時間軸；配樂交叉淡化。

    這一步我確認什麼b-roll 清單由我勾選後才下載

    用在：國際醫學解碼 EP5（時間軸示意）

  6. STEP 05

    重點字卡上字

    字幕台詞＋我的字卡範本 → 字卡批次放上時間軸

    用自己在 Premiere 做的字卡範本，照台詞批次換字、放上時間軸。黃字放數字和結論，白字放鋪陳。

    這一步我確認什麼字卡清單由我改過才上字

    用在：國際醫學解碼 EP5 的重點字（這裡用六種文字特效示範）
